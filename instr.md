Ты опытный full-stack разработчик. Построй веб-приложение «Cold Call Arena» — соревновательный трекер холодных звонков для двух братьев-сооснователей студии разработки. Один звонит из Бишкека (UTC+6), другой из Найроби (UTC+3). Продукт один: сайты, автоматизация бизнес-процессов и интеграция ИИ для среднего бизнеса. Регионы разные, поэтому система должна быть честной при разных рынках.

Сначала покажи мне план: структуру проекта, схему БД и порядок работы. Жди моего подтверждения, потом строй. Работай поэтапно: сначала MVP (Этап 1), затем проверка, затем следующие этапы.

## Стек
- Next.js (App Router) + TypeScript + Tailwind
- Supabase: Postgres, Auth (magic link по email), Realtime для живой ленты и счётчиков
- Деплой на Vercel
- PWA (manifest + service worker), чтобы добавить на главный экран телефона
- Интерфейс на русском языке, mobile-first

## Пользователи
Ровно два игрока, у каждого свой часовой пояс в профиле. «День» и «неделя» (пн–вс) считаются по локальному времени каждого игрока. Доступ только по whitelist из двух email (переменная окружения).

## Модель данных (предложи улучшения при необходимости)
- players: id, name, email, timezone, region_label, avatar_color
- leads: id, owner_id, company, contact_name, phone, industry, city, status (new / contacted / meeting_set / meeting_held / proposal / won / lost), notes, created_at. Импорт из CSV (экспорт Google Sheets), с сопоставлением колонок.
- activities: id, player_id, lead_id (обязательно для всего, кроме «звонок без ответа»), type (call / conversation / rejection / meeting_set / meeting_held / proposal / deal / followup), industry, offer (website / automation / ai / mixed), deal_value (для сделок, в USD), objection_id (опционально), script_id (опционально), note, created_at, points
- scoring_rules: тип действия → очки. Редактируется в настройках, НЕ хардкодить. Значения по умолчанию: call 1, conversation 3, rejection 2, followup 1, meeting_set 10, meeting_held 10, proposal 25, deal 100 + 1 очко за каждые $100 суммы сделки.
- objections: id, text, author_id, created_at
- scripts: id, objection_id, text, author_id. Если игрок логирует встречу с пометкой «использовал скрипт X» и автор скрипта — другой игрок, автор получает +5 бонусных очков.
- weekly_goals, achievements, quests, blitz_sessions, penalties (текст наказания за проигрыш недели)

Правила целостности: meeting_held возможен только если по лиду был meeting_set; при логировании действия статус лида обновляется автоматически. Действия можно отменить в течение 10 минут (кнопка «Отменить»), потом только с пометкой в ленте.

## Этап 1 — MVP
1. Вход, профили, импорт лидов из CSV, список лидов с поиском и фильтром по статусу.
2. Экран «Звоню»: выбор лида и крупные кнопки действий (пальцем на телефоне). Для conversation и выше — быстрый выбор отрасли и оффера. Логирование в 1–2 тапа.
3. Главный экран «Арена»: счёт недели «я vs брат» крупно, прогресс к общей цели месяца, живая лента событий обоих (Realtime), сегодняшние цифры каждого.
4. Недельный итог: трофей «Объём» (больше очков) и трофей «Рост» (очки недели / средние очки игрока за 4 предыдущие недели; первые 2 недели «Рост» не присуждается, показывается «калибровка»).

## Этап 2 — Игровые механики
- Серии: дни подряд с выполненным минимумом (минимум настраивается, по умолчанию 20 звонков). Учитывать выходные дни, которые игрок отметил как нерабочие.
- Ежедневный квест: одинаковый для обоих, выбирается детерминированно по дате из списка (например, «проведи 5 живых разговоров в одной отрасли», «назначь 2 встречи»), бонус 15 очков.
- Достижения со значками: «Первая кровь» (первая встреча), «Броня» (10 отказов за день), «Снайпер» (встреча с первого звонка лиду), «Марафонец» (серия 10 дней), «Закрыватель» (первая сделка), «Учитель» (твой скрипт принёс брату встречу). Анимация при получении.
- Power Hour (блиц): любой игрок запускает сессию на 60 минут, второй получает приглашение. Во время блица — полноэкранный живой счётчик обоих и таймер. Очки за действия в блице ×2. Показывать подсказку, что окно пересечения — 13:00–18:00 Бишкек / 10:00–15:00 Найроби.
- Сезоны: календарный месяц, чемпион сезона, архив прошлых сезонов.
- Понедельник: каждый ставит цель на неделю. Пятница/воскресенье: экран итогов с победителями и текстом наказания проигравшего.

## Этап 3 — Аналитика и обучение
- Конверсии по воронке для каждого игрока: звонок → разговор → встреча → проведённая → КП → сделка.
- Разрезы по отрасли и офферу: где выше конверсия во встречу, отдельно по регионам. Вывод в виде «Что работает»: топ-3 комбинации отрасль+оффер в каждом регионе.
- Лучшее время для звонков: тепловая карта конверсии в разговор по часам (локальное время игрока).
- База возражений и скриптов: частота каждого возражения, какие скрипты чаще приводят к встрече.
- Воронка в деньгах: сумма КП и сделок.

## Этап 4 — Telegram-бот (опционально)
- Команды для быстрого логирования: /call, /talk, /no, /meet, /held, /kp, /deal <сумма>, с выбором лида из последних.
- Уведомления второму игроку о встречах, сделках, достижениях, обгоне в счёте недели, приглашении на блиц.
- Утреннее сообщение каждому в 9:00 по его времени: квест дня, счёт недели, серия.
- Используй webhook на Vercel, токен бота в переменных окружения.
